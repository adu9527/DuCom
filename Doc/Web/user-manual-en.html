Install and Start

GitHub Releases provide one approximately 78 MB DuCom.exe (the size may vary slightly between versions). It includes the required .NET runtime and dependencies; no installer or separate runtime is needed.
  1. Open GitHub Releases.
  2. Download the latest DuCom.exe.
  3. Place it in a permanent writable folder.
  4. Double-click it.

Verify the official repository before accepting a Windows security prompt. Do not run it directly inside an archive.

Quick Connection

  1. Connect the board or USB serial adapter.
  2. Refresh and select the COM port.
  3. Review baud, data bits, stop bits, parity, flow control, and encoding.
  4. Connect; each port receives an independent session.
  5. Read output in the log and send commands below.

115200 / 8 / 1 / None is common, but must match the firmware.

Receive Display and Logs

STR / HEX / ANSI

STR supports UTF-8, ASCII, GBK/GB2312; HEX is for binary protocols; STR can render common ANSI/VT styling.

Automatic Logs

Asynchronous file output with directory, naming, and rotation. Display trimming never removes data already written to disk.

Configure timestamps, wrapping, line numbers, control markers, font, and size. Pausing follow affects presentation only.

Send Data

STR

None, CR, LF, and CRLF line endings; escapes include \r, \n, \t, \\, and \xNN.

HEX

Enter complete byte pairs such as AA 55 01 0D 0A. Invalid bytes are rejected.

History, Timing, Commands

Search, delete, or restore history. Timed send has a 50 ms minimum. Command groups add delay, result checks, timeout, loops, and multiple targets.

Search, Highlight, and Filter

  • Plain or regex search with previous/next navigation.
  • Contains/Regex styling with colors, bold, and italic.
  • Filtering can be enabled per port.
  • Regex timeouts protect the UI; rule projects can be imported/exported.

Sessions, Split View, and Floating Windows

Run multiple independent ports. Drag sessions into horizontal or vertical two-pane layouts and persist the split ratio. Quad view is not currently supported. Floating windows remain bound to their port.

Tool Center

  • Virtual ports: com0com pair management; some actions require elevation.
  • Telnet: local shell and serial bridge. Remote mode requires authentication and a trusted network.
  • WatchDog: alert, log, or send when expected content is absent.
  • Runtime/variables: CPU, memory, GC, threads, regex values, and CSV export.
  • Plugins: background image is available; external DLL metadata is read but not executed.

Troubleshooting

Port missing or busy

Check the driver, cable, hidden-port filters, and other serial programs; reconnect and refresh.

Garbled text

Match both baud rate and encoding. Some firmware uses GBK/GB2312.

HEX rejected

Use two hexadecimal characters per byte, for example 01 0A FF.

Remote Telnet failure

Check address, firewall, port, and authentication. Never expose it to an untrusted network.
