DuCom 用户手册

从下载 EXE 到多串口、日志、命令组和网络工具的完整使用说明。

安装与启动快速连接接收与日志数据发送搜索与过滤多会话与分屏工具中心故障排查反馈支持

安装与启动

GitHub Release 提供一个约 78 MB 的 DuCom.exe（不同版本可能略有浮动）。所有 .NET 运行环境和依赖已经打包，无需安装运行库或执行安装向导。
  1. 前往 GitHub Releases。
  2. 下载最新 DuCom.exe。
  3. 放到有写入权限的长期目录。
  4. 双击运行。

Windows 出现安全提示时，请先确认文件来自官方仓库。不要直接在压缩包中运行。

快速连接

  1. 连接开发板或 USB 转串口设备。
  2. 刷新左侧串口列表并选择 COM 口。
  3. 确认波特率、数据位、停止位、校验、流控与编码。
  4. 点击连接，DuCom 为每个端口创建独立会话。
  5. 在日志区查看输出，在发送区输入命令。

常见组合为 115200 / 8 / 1 / None，实际参数必须与固件一致。

接收显示与日志

STR / HEX / ANSI

文本模式支持 UTF-8、ASCII、GBK/GB2312；HEX 适合二进制协议；STR 可渲染常见 ANSI/VT 样式。

自动日志

异步写盘，支持目录、文件名和分片设置。显示预算裁剪旧内容不会删除磁盘日志。

可配置时间戳、自动换行、行号、CR/LF、空格、Tab、字体和字号。暂停跟随只影响显示，不停止接收和写盘。

数据发送

STR

支持 None、CR、LF、CRLF；转义解析支持 \r、\n、\t、\\、\xNN。

HEX

输入完整字节对，例如 AA 55 01 0D 0A。非法或不完整字节不会发送。

历史、定时与命令组

历史可搜索、删除和填回；定时发送最小 50 ms。高级命令支持延时、返回检查、超时、循环与多端口目标。

搜索、高亮与过滤

  • 普通文本或正则搜索，上一个/下一个结果。
  • Contains/Regex 高亮，支持颜色、粗体和斜体。
  • 过滤可按端口独立启用。
  • 正则有超时保护，规则可导入导出。

多会话、分屏与浮窗

多个端口可并行运行并独立保存状态。拖动会话可形成左右或上下双分屏并保存比例；当前版本无四宫格。浮窗固定绑定端口，可置顶、清屏、保存、切换 STR/HEX 和发送命令。

工具中心

  • 虚拟串口：com0com 端口对管理，部分操作需管理员权限。
  • Telnet：本地 Shell 与串口桥接；远程监听必须认证，只用于可信网络。
  • WatchDog：缺少期望内容时告警、记录或发送命令。
  • 运行/变量监视：CPU、内存、GC、线程、正则变量值与 CSV 导出。
  • 插件：背景图可用；外部 DLL 当前只读元数据，不执行。

故障排查

找不到或打不开串口

检查驱动、数据线、隐藏端口和端口占用，重新插拔后刷新。

乱码

同时核对波特率与编码；中文固件可能使用 GBK/GB2312。

HEX 失败

每个字节必须是两个十六进制字符，例如 01 0A FF。

Telnet 无法远程连接

检查监听地址、防火墙、端口和认证。不要暴露到不可信网络。
