1. DuCom 是什么

Windows 上的串口工具，面向嵌入式调试和蓝牙音频开发。

可以同时打开多个串口，日志自动存盘，按规则高亮和过滤，把常用命令编成组批量执行。插件提供固件校验码、CRC 计算、耳机产测、语音合成等功能。

2. 安装与启动

Release 页面提供三个包，按需要选一个：

文件说明体积
DuCom-win-Setup.exe安装版，装进开始菜单，走安装版更新约 130 MB
DuCom.exe完整便携版，单文件，自带 .NET 运行时约 79 MB
DuCom-lite.exe轻量便携版，单文件，使用系统已装的 .NET 10约 17 MB

体积随版本变化，以 Release 页面为准。

便携版不需要安装，放到有写入权限的目录，双击运行即可。不要直接在压缩包里运行，否则日志和配置可能写不进去。

lite 版要求系统已安装 .NET 10 桌面运行时。没有安装时，程序会提示下载；不想安装运行时，请使用完整版。

首次启动 Windows 可能弹出安全提示。确认文件来自本仓库的 Release 再运行。

启动后会先显示封面页，可以在「设置 → 外观」里关闭，也可以只关掉动画。

3. 连接串口

  1. 接上 USB 转串口或开发板。
  2. 点左侧串口栏的刷新按钮。
  3. 选中目标端口。
  4. 在「串口参数」里确认波特率、数据位、停止位、校验、流控和编码。
  5. 点连接，或者按 Ctrl+Enter。

每个端口会开一个独立会话，参数、日志和发送内容互不影响。

常见参数是 115200 / 8 / 1 / None，以设备固件为准。端口被别的软件占用时，先关掉占用程序。

打开失败时，会话里会给出原因，可以直接重试。

4. 主界面

  • 顶部菜单：文件、编辑、视图、工具、插件、关于。
  • 串口侧栏：刷新、排序、筛选、隐藏端口、打开/关闭。
  • 会话区：每个串口一个标签，可以左右或上下分屏。
  • 日志区：接收和发送记录，支持搜索、高亮、过滤、跟随和保存。
  • 发送区：STR/HEX、换行、转义、发送历史、定时发送。
  • 状态栏：连接状态、收发计数和错误提示。

侧栏可以通过「视图 → 侧边栏」或 Ctrl+B 收起，为日志留出更多宽度。

标题栏右侧有内存占用显示，在设置里可以关掉。

5. 串口参数

支持波特率、数据位、停止位、校验位、流控、编码、DTR、RTS 和丢弃 NUL 字节。波特率可以手动输入，常用的自定义值会保存下来。

部分接收参数在打开端口时固定，改完需要关闭再打开会话。

启用自动重连后，设备意外拔出再插上，DuCom 会尝试恢复原来的端口。手动断开不会触发重连。

6. 接收与显示

6.1 STR / HEX

STR 模式按选定编码显示文本，支持 UTF-8、ASCII、GB2312、GBK 等。HEX 模式按字节显示，适合二进制协议。

STR 模式能渲染常见 ANSI/VT 转义序列，包括颜色、粗体、下划线、反显、256 色和 RGB。

6.2 时间戳与显示选项

时间戳格式可以选，常见形式是 [HH:mm:ss.fff]。还可以打开行号、自动换行、当前行高亮，以及 CR/LF、空格、Tab 的可视化标记。

字号在「视图 → 字号」里调，日志字体在「设置 → 外观」里改。

暂停跟随只停显示，接收和写盘照常进行。

6.3 自动保存与分片

打开自动保存后，接收数据异步写入日志文件。可以设置：

  • 日志目录
  • 文件名格式，支持 {Port}、{yyyy}、{MM}、{dd}、{HH}、{mm}、{ss}、{fff} 等占位符
  • 是否按大小分片，以及单个文件的大小上限

文件名格式下方有实时预览。分片只在达到大小时触发，不按时间切。

6.4 显示预算

每个会话有显示内存预算，默认 64 MB。日志超过预算时，界面会淘汰较早的内容，磁盘上的日志不受影响。

被淘汰时会显示提示，不表示串口丢数据。

6.5 保存与打开

「文件 → 保存日志为」可以把当前可见内容存成文本、HEX 或二进制。

「文件 → 打开日志」调用系统默认程序打开日志文件，只读查看，不会导入当前会话。要在 DuCom 里分析日志，用「工具 → 日志分析器」。

7. 搜索、高亮与过滤

7.1 搜索

会话内搜索支持普通文本和正则，可以区分大小写、匹配整行，用上一个/下一个跳转。正则有超时保护，写错了不会把界面卡死。

7.2 高亮

「工具 → 高亮与过滤」管理规则。匹配方式有包含和正则两种，命中后可以改前景色、背景色、加粗、斜体。

内置了 BES 常用的几套模板：Error、Warning、Status、Fault、Audio、Address、Unit、Version。规则可以自己加，也能导入导出。

7.3 过滤

过滤规则决定哪些行显示在界面上，不影响接收和落盘。规则可以按端口启用或停用。

8. 发送

8.1 STR 发送

输入文本，换行方式可选 None、CR、LF、CRLF。

打开「解析转义」后，支持 \r、\n、\t、\\ 和 \xNN。

8.2 HEX 发送

输入完整的十六进制字节对，例如 AA 55 01 0D 0A。空格可有可无。

字节不完整或包含非法字符时不会发送。HEX 模式不解析 STR 转义。

8.3 发送记录前缀

日志里显示发送内容时，可以加一个前缀，默认是 TX > 。

这个前缀只影响日志显示，不会写进串口数据。不想看可以在设置里关掉。

8.4 发送历史

发送过的内容会自动记录并去重。输入框里用上下方向键翻，或者到「工具 → 发送历史」里搜索、删除、清空、重新填入。

8.5 定时发送

设置间隔后循环发送当前内容，最小间隔 50 ms。

发送频率过高可能导致设备无响应，开始前先确认设备能承受。

8.6 从文件发送

可以读取文本文件作为发送内容，适合长脚本或批量指令。

9. 命令组

「工具 → 命令组」打开编辑器。

一个命令组里可以放多条命令，每条设置：

  • 发送内容（STR 或 HEX）
  • 发送后延时
  • 等待回复的超时时间
  • 期望的回复内容

运行时可以选一个或多个目标端口，比如左右耳同时发。每条命令会显示当前状态：发送中、等回复、通过、超时、发送失败。

某个端口失败不会自动中断其他端口。停止后当前轮次记为中止。

命令组支持新建、重命名、删除、导入和导出。导出的文件可以直接发给同事。

10. 多串口、分屏与悬浮窗

多个串口可以同时运行，每个会话独立保存参数和状态。

把一个会话拖到右侧可以形成左右分屏，也可以切换成上下分屏。分屏比例会保存。

「视图 → 悬浮发送」打开一个小窗，绑定当前端口。可以置顶、固定滚动、清屏、保存、切换 STR/HEX 和发送命令。主窗口切到别的标签后，小窗继续更新。

悬浮窗的位置和大小按端口分别保存。

11. 工具中心

「工具 → 工具中心」包含七个页签：

工具用途
监控CPU、内存、私有内存、线程数；也能用正则提取变量值并导出
虚拟串口检测 com0com，创建和删除虚拟串口对，部分操作需要管理员权限
ASCII 表查 DEC、HEX 和 ASCII 对应关系
参考资料打开仓库内的架构、测试和开发文档
Telnet本地 Telnet 服务，可把客户端输入桥接到指定串口
WatchDog在设定周期内没等到期望内容时告警、记日志或发送命令
发送历史搜索、复用、清理所有发过的内容

Telnet 默认只监听本机。开启远程监听会暴露串口数据，必须同时启用认证，并且只在可信网络里用。

12. 日志分析器

「工具 → 日志分析器」可以打开历史日志，也可以接实时会话。

支持按时间、级别、模块、关键词筛选，规则能导入导出，结果可以导出成表格。

分析 BES 日志时会解析启动流程、fault、蓝牙 HCI 和 Profile 事件，左侧分析树可以直接跳到对应段落。排查别人发来的日志时，不需要从头翻。

13. 插件

插件按 DPP/1 协议开发，每个插件跑在独立进程里。某个插件崩了，串口收发不受影响。

「设置 → 插件」可以查看已安装插件、版本、能力、权限和运行状态，也可以启用、停用或打开插件页面。

仓库内置七个插件。

13.1 校验码查询

拖入固件，或者按 Ctrl+O 选择文件。支持杰理、蓝讯，恒玄需要先按接入文档配置一次（接入说明在插件详情页，离线可看）。

结果会显示校验码、默认蓝牙名、芯片型号、厂商和编译时间。底部会区分几种状态：整份固件校验通过、CRC 校验通过、仅读到校验码、未识别到校验码。

窗口可以置顶，方便对着烧录工具核对。校验码可以一键复制。

13.2 CRC 计算

支持 Hex 和 ASCII 输入，也支持直接校验文件，文件上限 64 MiB。

内置 21 种常见 CRC 模型，也可以自定义 1 到 32 位的宽度、多项式、初值、异或值和输入输出反转。

结果可以复制成 Hex 或 Bin。按 Ctrl+Enter 计算，窗口支持置顶。

13.3 语音合成

使用微软在线语音，内置 318 个音色。可以调语速、音调、音量，先试听再合成。

支持导入 TXT 和 MD，长文会自动分块，界面显示合成进度。MP3 和 SRT 字幕可以分开导出。

输出目录默认跟随日志目录，也可以自己指定。需要联网，代理默认跟随系统，也可以单独配置 HTTP/SOCKS5 代理。

13.4 耳机产测

左右耳各接一个串口，最多两个通道。

流程是：选项目，勾选左耳/右耳和对应 COM 口，连接，开始。勾了哪个通道就测哪个，循环执行时每轮重新开始。

测试项在「项目配置」里定义：

  • 发送内容：帧头、长度、CMD、CRC，长度留空会自动计算
  • 回复解析：按协议顺序添加字段，比如 MAC 固定 6 字节
  • 超时和发送后间隔
  • 是否启用

默认帧头是 55 AA，CRC 用 CRC8/MAXIM。

「计算报文（不发送）」只做本地组帧和 CRC，不开串口，用来核对配置。

支持复合命令：把多条子命令合成一项，可以设置左右角色和数据引用，比如把左耳读到的 MAC 写给右耳。

每轮自动生成 .log 和 .csv，CSV 是 UTF-8 BOM，Excel 能直接打开。统计里分别显示通过、不通过和中止，中止的轮次不计入完成数。

项目配置是 JSON，放在程序目录的 profiles 下，可以导入导出。

13.5 背景图

主窗口底层可以铺一张背景图，不影响日志选择、复制和分屏。

支持选文件夹随机轮播，设置透明度和切换间隔。

13.6 日志打包

标题栏的「一键打包」按钮，用来把问题现场整理成压缩包。

填写项目名称、测试人员、设备软件版本、复现概率、设备名、问题描述和复现步骤，勾选要打包的串口。系统日志也可以一起带上。

打包会生成结构化目录，日志副本按设备名命名。输出目录可以设置。

13.7 秒表

高精度计时，支持计次、暂停、继续。结果可以导出 CSV 或 Excel，适合量时序和统计。

15. 自动更新

「关于 → 检查更新」可以从 GitHub 获取最新版本。

三种包各有自己的更新通道：安装版走安装器更新，完整便携版和 lite 版下载对应的单文件替换。设置里可以开启自动检查。

16. 常见问题

找不到串口

确认驱动装好、数据线支持传输，然后刷新列表。检查是否被隐藏，必要时用「恢复隐藏端口」。

串口打不开

常见原因是端口被占用、权限不足或参数不合法。关掉其他串口软件，重新插拔设备再试。

显示乱码

核对波特率和编码。中文固件常用 GBK/GB2312，新一些的固件多用 UTF-8。

HEX 发送没反应

每个字节要两位十六进制，比如 01 0A FF。有非法字符时 DuCom 不会发送。

界面不滚了，日志还在不在

在。暂停跟随只影响显示位置，接收和自动写盘继续。

日志被裁掉了

显示预算到了上限，旧内容从界面淘汰，磁盘日志不受影响。想保留全部内容，调大预算或直接看日志文件。

Telnet 连不上

检查监听地址、端口、防火墙和认证设置。远程模式必须启用认证。

插件打不开

到「设置 → 插件」看状态。插件被禁用、版本不匹配或权限未批准时不会启动，详情里会给出原因。

18. 安全提示

  • 只从官方 GitHub Release 下载。
  • 谨慎发送会擦除固件、改写 Flash 或改变安全状态的命令。
  • 远程 Telnet 只在可信网络开启。
  • 外发日志前先脱敏。
