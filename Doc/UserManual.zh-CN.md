# DuCom 用户手册

[English](UserManual.en-US.md) · [开发者文档](DeveloperGuide.zh-CN.md) · [网页版](Web/user-manual-zh.html) · [GitHub](https://github.com/adu9527/DuCom)

> 适用平台：Windows 10 或更高版本  
> 文档更新：2026-09-02

## 1. DuCom 是什么

DuCom 是一款面向嵌入式设备调试、高吞吐串口日志和多端口协作场景的 Windows 串口工具。它支持多个串口独立会话、STR/HEX 收发、日志自动保存、搜索过滤、命令组、分屏、Telnet 桥接、虚拟串口和运行监控。

## 2. 安装与启动

DuCom 的 GitHub Release 直接提供一个约 78 MB 的单文件 `DuCom.exe`（不同版本可能略有浮动）。程序已经打包运行所需的 .NET 环境和依赖，不需要单独安装运行库，也没有安装向导。

1. 打开 [GitHub Releases](https://github.com/adu9527/DuCom/releases)。
2. 下载最新版本的 `DuCom.exe`。
3. 将 EXE 放到一个可长期使用且有写入权限的目录。
4. 双击 `DuCom.exe` 即可使用。

首次启动若 Windows 显示安全提示，请确认文件来自 DuCom 官方 GitHub 仓库后再选择运行。日志、设置和用户数据会在程序目录或用户本地应用数据目录中生成；不要直接在压缩包内运行。

## 3. 快速连接串口

1. 连接 USB 转串口设备或开发板。
2. 在左侧串口列表点击刷新。
3. 选择目标 COM 口。
4. 打开“串口参数”，确认波特率、数据位、停止位、校验位、流控和编码。
5. 点击连接。每个串口会创建独立会话标签页。
6. 设备输出会显示在日志区；在底部发送区输入命令并发送。

常见默认组合为 `115200 / 8 / 1 / None`，但必须以设备固件配置为准。端口被其他软件占用时，请先关闭占用程序。

## 4. 主界面

- **顶部菜单**：文件、视图、工具、关于。
- **串口侧栏**：刷新、隐藏/显示、排序、连接和端口信息。
- **会话标签**：每个端口独立连接、显示、发送和日志配置。
- **日志区**：显示接收和发送记录，支持跟随、冻结、清屏、搜索与保存。
- **发送区**：STR/HEX、换行方式、转义解析、文件发送和定时发送。
- **状态区**：显示连接状态、串口错误和操作结果。

## 5. 串口参数

DuCom 支持波特率、数据位、停止位、校验、流控、编码、DTR、RTS 和丢弃 NUL 字节。可添加自定义波特率。部分接收和显示参数在会话创建时固定，修改后需要关闭并重新打开端口。

启用自动重连后，DuCom 会在设备意外拔出并重新出现时尝试恢复同一端口；手动断开不会触发自动重连。

## 6. 接收显示与日志

### 6.1 STR / HEX

- **STR**：按所选编码显示文本，支持 UTF-8、ASCII、GB2312、GBK 等。
- **HEX**：以十六进制字节形式显示，适合二进制协议。
- **ANSI/VT**：STR 模式可渲染常见颜色、粗体、下划线、反显、256 色和 RGB 转义序列。

### 6.2 时间戳与显示

可选择时间戳格式、自动换行、行号、当前行高亮、显示 CR/LF、空格与 Tab，并调整日志字体和字号。暂停自动滚动不会停止接收和磁盘日志。

### 6.3 自动日志

开启自动保存后，接收数据异步写入日志文件。可配置日志目录、文件名格式、滚动分片和单文件大小。显示区有内存预算，超出预算时会裁剪较早的显示内容，但已写入磁盘的日志不受影响。

### 6.4 保存与载入

“文件”菜单支持将当前可见日志保存为文本、HEX 或二进制。加载已有日志时，DuCom 使用系统关联程序只读打开文件，不会将文件导入当前串口会话。

## 7. 搜索、高亮与过滤

- 会话内搜索支持普通文本、正则表达式、大小写匹配以及上一个/下一个结果。
- 高亮规则支持 Contains/Regex、前景色、背景色、粗体和斜体。
- 过滤规则可按端口启用或关闭。
- 复杂正则会受到超时保护，避免长时间阻塞界面。
- 规则项目支持保存、导入和导出，便于在多台电脑之间共享。

## 8. 数据发送

### 8.1 STR 发送

输入普通文本，可选择 None、CR、LF 或 CRLF 换行。启用“解析转义”后支持 `\r`、`\n`、`\t`、`\\` 和 `\xNN`。

### 8.2 HEX 发送

输入完整的十六进制字节对，例如 `AA 55 01 0D 0A`。HEX 模式不解析 STR 转义。字节不完整或包含非法字符时不会发送。

### 8.3 发送历史与定时发送

发送历史会自动去重并保存最近记录，可通过上下方向键浏览，也可在工具中心搜索、删除、清空或填回输入框。定时发送的最小间隔为 50 ms，使用前应确认设备能够承受发送频率。

### 8.4 文件与命令组

可读取文本文件作为发送内容。高级命令支持命令组 CRUD、导入导出、延时、返回结果检查、超时、循环执行和多目标端口。单个目标端口失败不会自动中断其他端口。

## 9. 多会话、分屏与浮窗

DuCom 可同时打开多个串口，每个端口独立保存参数和状态。可将会话拖到右侧形成左右或上下双分屏，调整比例并保存布局。当前版本不提供四宫格。

浮窗发送/迷你日志窗口固定绑定一个端口，可置顶、清屏、保存、切换 STR/HEX、发送命令，并在主界面切换到其他标签后继续更新。

## 10. 工具中心

- **虚拟串口**：检测 com0com，并通过 `setupc.exe` 管理端口对；部分操作需要管理员权限。
- **Telnet 服务**：启动本地 Telnet Shell，可将客户端输入与指定串口双向桥接。远程监听会暴露串口数据，必须启用认证并仅在可信网络中使用。
- **WatchDog**：在指定周期内未检测到期望内容时提示、记录诊断日志或发送命令。
- **运行/变量监视**：显示 CPU、内存、GC、线程以及正则提取的变量值，可导出 CSV；当前版本不绘制趋势图。
- **ASCII 表**：快速查询 DEC、HEX 和 ASCII。
- **插件管理**：背景图片功能可用；外部 DLL 当前仅发现并显示元数据，不自动加载执行。
- **SuperCom 数据导入**：以只读方式发现兼容工具的数据库或数据目录，并迁移可识别的配置。

## 11. 设置、主题与快捷键

DuCom 支持浅色/深色主题和简体中文/English，即时切换。常用设置、端口覆盖、会话布局、隐藏端口、发送历史、命令组和规则会持久化。

快捷键管理支持搜索、编辑、冲突检测、清除和恢复默认。可配置打开/关闭串口、刷新、清屏、保存日志、跟随、侧栏、工具中心、搜索、发送模式等操作。

## 12. 常见问题

### 找不到串口

确认设备驱动已安装、数据线支持数据传输，然后刷新列表。检查是否隐藏了端口，并尝试恢复全部隐藏端口。

### 串口无法打开

常见原因是端口被其他程序占用、权限不足或参数无效。关闭其他串口软件，重新插拔设备并检查参数。

### 乱码

确认波特率和编码与设备一致。中文固件常见 GBK/GB2312，现代终端通常使用 UTF-8。

### HEX 发送失败

每个字节必须由两个十六进制字符组成，可用空格分隔，例如 `01 0A FF`。

### 界面暂停但日志是否还在记录

暂停跟随或滚动仅影响显示位置，接收和自动写盘继续运行。显示内容因预算被裁剪时，磁盘日志仍保留。

### Telnet 无法远程连接

确认允许远程连接、监听地址、防火墙和端口；远程模式必须启用认证。不要在不可信网络开放服务。
