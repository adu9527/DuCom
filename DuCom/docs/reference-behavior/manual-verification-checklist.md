# DuCom 手工验收清单 — 2026-08-28（GLM 长任务轮更新）

前置：`dotnet run --project src\DuCom`，分别以 zh/en × Light/Dark 四组启动核对无缺失键（缺键会显示原始键名）。

## A. 启动与外壳
- [ ] 960×640 / 1366×768 / 1920×1080 三档布局：日志区与发送区均可见
- [ ] 标题栏菜单：文件/编辑/工具/帮助全部展开无占位文本
- [ ] 关闭窗口：日志 flush 完成后进程正常退出（退出码 0）
- [ ] 迷你窗开启时关主窗：随主窗一并退出

## B. 快捷键
- [ ] F5 刷新 / Ctrl+L 清屏 / Ctrl+P 跟随 / Ctrl+B 侧栏 / Ctrl+T 工具中心
- [ ] F11 最大化还原 / Ctrl+D 焦点发送框 / Ctrl+S 保存可见日志
- [ ] Ctrl+Enter 开关选中口；Ctrl+W 关会话；Ctrl+Shift+W 关右分屏；Alt+E HEX；Alt+D 时间戳；Ctrl+Shift+M 发送模式
- [ ] 工具页编辑快捷键 → 冲突被拒绝 → 重启保留；恢复默认生效
- [ ] shortcuts.json 写入手工破坏后启动回退默认且 ducom.log 有告警

## C. 连接与状态
- [ ] 选不同波特率连接 COM 设备；错误参数产生 fault 横幅但不闪退
- [ ] Frame/Parity 告警以**中文/英文本地化文字**出现在警告条（不断线）；拔出 USB → 会话转故障态，端口列表图标变红
- [ ] 打开失败不留死 Tab；关闭中按钮禁用
- [ ] 发送到已拔出设备 → 状态栏“发送失败：…”双语提示，不闪退
- [ ] **设备持续高速输出时关闭端口**：若设备输出快于排空，关闭在预算（约 5 秒或 32MB）后完成，会话显示包含 "drain exceeded" 的双语故障与剩余字节数说明——这是显式报告（非静默丢数据、非无限卡死）；输出停歇后关闭则无该故障

## D. 日志显示
- [ ] 设备输出 ANSI 彩色（`\x1b[31m…`）：颜色/粗体/下划线渲染正确、无 ESC 字符残留
- [ ] 跨接收块截断的 CSI 序列不产生花字
- [ ] HEX 模式下含 "1B 5B" 的数据不被误解析为样式
- [ ] 高亮规则着色 + 过滤规则隐藏行，保存规则后当前会话立即生效，左右 pane 同规则独立过滤
- [ ] **灾难性正则（如 `(?<x>a+)+b`）高亮/过滤规则：行保持可见、出现一次超时告警、界面不冻结**
- [ ] **搜索框输入灾难性正则 → 双语“执行超时”提示；改普通文本搜索立即恢复**
- [ ] 长时间运行后出现“已丢弃最早 N 行”提示（左下角），同时 .txt 日志完整
- [ ] 清屏只清显示，磁盘日志继续追加；冻结期间接收不停
- [ ] 编辑菜单：自动换行开→长行按字符折行；行号列出现；当前行高亮开关生效；显示 CR/LF、空格、Tab 的替换符号正确；字号切换即时生效且重启保留

- [ ] 看门狗页建规则（期望内容=设备心跳、周期 10s、动作=提示）→ 停止设备心跳 → 警告条出现触发提示；恢复心跳后不再触发；throttle 内不重复
- [ ] 看门狗动作=发送命令 → 触发时命令进入 TX 日志

- [ ] 监视器页建变量规则（正则首捕获组）→ 设备输出匹配行 → 实时值/次数更新；导出 CSV 内容正确
- [ ] Telnet：设端口启动 → **工具页显示实际监听地址（默认 127.0.0.1）**；`telnet localhost <port>` 出现欢迎语；绑定串口会话后设备输出推送到 telnet 终端；在 telnet 输入多行文本（含中英混排、CR/LF/CRLF 混用）→ 每行各成一条串口发送（TX 日志逐行可见）；断开 telnet 客户端列表更新
- [ ] Telnet 重启循环：启动→停止→再启动（反复 3 次）每次都能连上并收到欢迎语；停止两次连续调用无异常；关闭工具页后再启动服务正常（释放/重绑端口）

- [ ] 隐藏端口重启保留：右键隐藏某端口（或从 SuperCom 迁移含隐藏端口）→ 重启 DuCom → 该端口仍默认隐藏；"恢复全部隐藏端口"后重启不再隐藏
