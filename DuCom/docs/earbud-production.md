# 耳机产测 · 生产界面版

运行 DuCom.exe，在插件菜单打开“耳机产测”。

## 操作

选择项目 → 勾选左耳 / 右耳并选择 COM → 连接 → 开始。

最多两个通道；勾选哪个就测试哪个。循环勾选后重复执行，停止后本轮记为中止。普通命令不含通道配置，按主页选择的通道执行。

主页只有项目、连接区、测试项与左右结果、开始 / 停止 / 循环及统计。不显示 HEX 和详细日志。

开始和每轮循环清除旧结果。勾叉固定在左右结果格右侧；文本超过 40 字符截断，点击打开完整内容。默认跟随当前执行项，滚轮查看时暂停跟随。底部左右完成信号分别显示通过、不通过或中止。“清空记录”只重置本批次统计和显示，不删已保存文件。

## 配置

“项目配置”集中管理项目名称、波特率、循环间隔、命令启用和导入导出。勾选启用才执行并显示在主页。

每条命令最右侧“详情”填写：名称、发送后间隔、应答超时，以及发送 / 回复的帧头、长度、CMD、CRC。长度留空自动计算。默认 55 AA、CRC8/MAXIM。

回复数据按协议顺序添加字段。MAC 固定 6 字节，一个命令返回两个 MAC 就添加两行。字段起点自动根据回复 CMD 推导；字段名称会出现在多字段结果中。

“计算报文（不发送）”仅本地组帧与 CRC 计算，不开串口。动态数据用“示例 HEX”填入已知字节，留空按 00 计算；示例不参与实际数值判定。

打开 ANC 示例：

- 发送 CMD `A6 01`，长度 2 → `55 AA 02 A6 01 A0`
- 回复 CMD `A6 02`，长度 2 → `55 AA 02 A6 02 42`

## 日志与统计

点击开始自动在 DuCom 当前串口日志目录创建同名 `.log` 和 `.csv`。日志包含完整 TX/RX，CSV 包含轮次、通道、测试项、结果、单项状态、本轮状态。CSV 为 UTF-8 BOM，可用 Excel 打开。

每轮算一次测试。任一执行项超时、CRC 错、应答异常、解析失败或通道断开，该轮不通过；普通项失败后继续。停止的轮次记录为中止，不计入已完成统计。统计为当前插件运行期间累计。

## 自定义复合命令

项目配置中使用“添加复合命令”，自行添加、复制、删除或排序子命令。每条子命令通过“详情 / 解析”填写发送与回复、解析字段、发送后间隔、超时，并可本地计算 CRC。

主页输出可选择某一步的解析结果，或自定义完成提示；完成提示留空则汇总各步骤结果。复合命令在主页只占一行，左右通道分别输出结果和勾叉。普通复合命令跟随主页所选通道；某侧失败后停止该侧剩余步骤，另一侧继续。

需要组队等跨耳协作时，在子命令的“步骤协作 / 数据引用”中设置固定左右角色及前序回复来源、偏移、字节数。该情况下需连接两耳，任一步失败停止整个复合项，避免缺少数据仍写入。原 X8I 组队配置兼容，现在可自由编辑。

预置本机 MAC、电量、电压、对耳 MAC，不进入 DUT。左右耳分别接独立串口，现场端口可选。组队步骤默认未启用；已有组队流程保留左右角色与动态数据交叉引用，启用后才执行，未获得有效来源数据不会写入。

项目 JSON 位于程序目录 `profiles`，可导入导出分享。外置模块负责单线收发方向与电气时序。
